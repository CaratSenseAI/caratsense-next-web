# A-08 — Case Study Heroes (Named Clients)

**Used in:** §6 cards + `/case-studies/[id]` detail heroes · **Priority: P0**
**Pipeline:** ① GPT Image Gen ×9 · then ① again for the wireframe twins (see `A-07`)
**Deliver:** `public/case-studies/hero-01.webp` … `hero-09.webp` — 2400×1500

Nine images that must look like **one photographer shot all nine in one week.** Consistency
matters more than any individual image being spectacular.

Every prompt below is complete and standalone. The shared lighting, angle, grade and
composition language is written out in full in each one — that repetition is deliberate, and it
is what produces a coherent set without needing Whisk style-locking.

## hero-01 — Cake O Clock · home bakery

```
A photorealistic wide interior photograph of a small commercial bakery kitchen at
night, lit only by warm practical lights inside the space.

Steel prep tables, a rolling rack trolley loaded with cake boards, piping bags
standing in a jar, a cooling rack holding finished cakes, flour dust across one
work surface, a clipboard hanging on a hook.

A single warm overhead lamp is on above the main prep table, creating a defined
pool of light. Everything beyond that pool falls into deep shadow and near-black.

Camera: elevated three-quarter angle, roughly 30 degrees above eye level, wide
lens, looking down across the space. Deep focus.

Composition: the lit prep table sits in the lower-right third of the frame. The
upper-left and upper-centre are dark and visually quiet — headline text will sit
there. Roughly 40% of the frame is near-black negative space.

Rendering: photorealistic, cinematic, high contrast. Fine film grain. Warm
tungsten practicals against cool near-black shadows. Desaturated by about 10%.
Shadows lifted very slightly toward violet.

Do not include: people, faces, hands, brand logos, any legible text or signage,
lens flare, god rays, sparkles, daylight, bright even exposure, stock-photo
staging, food-styling gloss, watermark.
```

## The wireframe twins

Every hero ships as a **pair** — the photoreal shot plus a matched glowing wireframe of the
identical scene. On the §6 card, hover scrubs a CSS mask between them; on the detail page,
scroll drives the same wipe.

```
hero-0N.webp         the photoreal night shot
hero-0N-wire.webp    the matched wireframe twin
```

Generate the twins with the standalone prompt in
[`A-07-wireframe-twins.md`](A-07-wireframe-twins.md) §Step 2, feeding each approved hero back in
as the reference image. Two images, ten lines of CSS, and every case study gets a signature
interaction.

## Card composition safe zone

The §6 card overlays this on the image:

```
┌────────────────────────────────────┐
│ 01                      CAKE O CLOCK│  ← mono, --ink-3 / --gold
│                                     │
│ Running a Home Bakery               │  ← d2, must sit on dark
│ Like a Logistics Company            │
│                                     │
│         [ dark negative space ]     │
│                                     │
│                    [ lit subject ]  │
│                                     │
│ Home bakery · Mumbai         → Read │
└────────────────────────────────────┘
```

Check every image with its real title overlaid before approving. Upper-left going bright is the
most common reason a set has to be regenerated.

## Acceptance criteria

- [ ] All nine read as one shoot — same angle, same grade, same grain, same darkness
- [ ] Upper-left quiet enough for a two-line headline in all nine
- [ ] No people, no faces, no hands
- [ ] No brand logos — including the client's own
- [ ] No legible text anywhere in the image
- [ ] `hero-02` does not sparkle — it must read as a working bench, not a jewellery ad
- [ ] Nothing reads as stock photography of "small business owner succeeding"
- [ ] Wireframe twin geometry matches its photoreal partner — overlay at 50% and check
- [ ] Each ≤ 320KB at 2400px WebP; nine heroes + nine twins ≤ 5MB total
